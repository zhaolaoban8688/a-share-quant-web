# A股波段启动二次验证器 V1.1

这是现有技术选股器之后的独立二次验证层，不修改 `scan.py`、根目录 `index.html` 或原有扫描工作流。

## V1.1 工作方式

1. GitHub Actions 在工作日收盘后生成沪深主板全市场量化特征快照 `validator/data/latest.json`。
2. 手机打开 `validator/` 页面，分别粘贴“技术系统候选股”和“龙虎榜补充股”。
3. 网页只在候选池内进行机械评分、去重、来源标记和 Top 排名。
4. Quant Score 由市场环境、主线代理、板块、资金行为、基础质量代理、相对强度、风险收益七部分组成。

## 当前边界

V1.1 的“基本面/催化”仍是结构化基础质量代理，**不包含**最新新闻、政策、产业催化、机构观点和市场叙事，因此不能把 Quant Score 直接解释为真实成功概率。下一阶段会用历史候选信号做概率校准，再接 AI 终审。

## 数据与运行

- 实时/快照：AKShare 东方财富，失败时回退新浪。
- 历史日K：腾讯接口，失败时回退 AKShare。
- 行业映射/强度：复用现有 `scan.py` 行业数据模块。
- 自动快照：`.github/workflows/meta_validator_snapshot.yml`。

仅用于量化研究与复盘，不构成投资建议。
